ERP Middleware - Representative Log Examples

These excerpts match the current application log messages and verified test scenarios.
Framework timestamps, categories, event IDs, and exception stack traces are omitted for readability.
Customer email addresses and full request payloads are intentionally not logged.
Elapsed times can vary between runs.
For manual end-to-end testing, the optional X-ERP-Simulation header selects the Mock ERP behavior.
